# 🎯 Number Guessing Game (Python & Web)

A beginner-friendly project where the computer generates a random number between 1 and 100, and the player tries to guess it using "Too High" or "Too Low" hints.

---

## 📁 Files Included

1. **[`index.html`](index.html)** ⭐ - **Standalone Interactive Web Page**
   - **No terminal or server required!**
   - Double-click to open in any web browser.
   - Animated mystery box, real-time hint alerts, guess history trail, confetti win effect, and best score tracking.

2. **[`game.py`](game.py)** - **Python CLI Game**
   - Uses Python's `random.randint()`.
   - Organized into clean functions (`generate_random_number`, `get_user_guess`, `play_round`, `main`).
   - `try/except` input validation preventing crashes on invalid input.
   - Multi-round support with "Play again? y/n".

---
